# ALSA UCM Config for Android

This directory contains the ALSA Use Case Manager (UCM) configurations (`ucm2`) adapted for the Android build system using Soong (`Android.bp`) and optionally Make (`Android.mk`).

The build scripts and module files in this directory are auto-generated by the `gen_android_bp.py` script. 

## How it works

The `gen_android_bp.py` Python script maps `ucm2` contents to Android `prebuilt_usr_share` and `install_symlink` modules so that they cleanly map to `/vendor/usr/share/alsa/ucm2` on your Android target.

To maintain clean and modular packages, the script automatically parses the directory tree and the `.conf` file contents:
- **Vendor Splitting**: Configurations are grouped into separate `phony` packages for each hardware vendor (e.g. `alsa-ucm-conf-intel`, `alsa-ucm-conf-amd`, `alsa-ucm-conf-qualcomm`). This lets you selectively add specific UCM packages to your device's `PRODUCT_PACKAGES`.
- **Dynamic Codec Decommonization**: The script scans the `ucm2` files directly. If a codec in `ucm2/codecs/` is only ever included by configs from one vendor (e.g., `rt5645`), it gets safely packaged with that vendor rather than sitting generically in `alsa-ucm-conf-common`.

## Usage

To re-generate the Android build files, simply run:
```bash
python3 gen_android_bp.py
```

### Options

- `--soong-namespace`: Adds an empty `soong_namespace {}` declaration at the top of the root `Android.bp`.
- `--legacy`: Instead of using Soong's `install_symlink`, this generates `Android_<pkg>.mk` Makefiles containing `FAKE` modules with standard shell commands (`mkdir -p` and `ln -sf`) to ensure symlinks are correctly generated even on older or modified AOSP versions where `install_symlink` is not fully supported for `/vendor` paths.

### Skipped Files

The Android build system (Make/Soong) strongly dislikes modules or source paths that contain spaces. Any files or symlinks inside `ucm2` that contain a space in their name are explicitly skipped by the generator. A list of those omitted files is output to `skipped-android.txt`.
